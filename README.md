# Finite-Region Gravity Provenance

Public provenance repository for preregistration and timestamp records associated with **Finite-Region Gravity, Records, and Response**.

This repository is not the publication archive and does not assign DOIs. Its immediate purpose is to provide an independently hosted Git commit timestamp for frozen analysis specifications before protected validation data are inspected.

## WALLABY Gate-A/B Stage-0

The first provenance record freezes the v4.99 WALLABY pretarget analysis state before any validation source rows, validation kinematics, residuals, Gate-A/B statistics, or validation outcomes are inspected.

The authoritative scientific payload is stored in `WALLABY_v1_PRETARGET_v4.99_TIMESTAMP_PAYLOAD.txt`. The Git commit that adds that file is the Stage-0 timestamp reference.

Final manuscripts and DOI-bearing archival releases are intended to be deposited separately after the completion roadmap is closed.
